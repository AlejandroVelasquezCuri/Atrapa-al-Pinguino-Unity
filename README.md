# ¡Atrapa al Pingüino! - Videojuego Educativo Cooperativo (Unity)
Este repositorio contiene el código fuente y el proyecto en Unity del videojuego **"¡Atrapa al Pingüino!"**, desarrollado como parte de la tesis de investigación para el fortalecimiento de habilidades sociales en niños con Trastorno del Espectro Autista (TEA) de la Asociación Kolob Tacna.
## 📌 Descripción del Proyecto
"¡Atrapa al Pingüino!" es un videojuego educativo y cooperativo diseñado para tablets. En él participan 4 jugadores en turnos secuenciales de 20 segundos para mover, unir y rotar objetos geométricos con el objetivo común de acorralar a un pingüino que se desplaza aleatoriamente por el escenario.
## 🛠️ Especificaciones Técnicas
* **Motor de videojuegos:** Unity (Versión 2021.3 LTS o superior)
* **Lenguaje:** C#
* **Plataforma objetivo:** Tablets Android
* **Mecánica principal:** Turnos secuenciales, manipulación táctil de objetos y generación aleatoria de elementos.
## 📁 Estructura del Repositorio
* `/Assets/Scripts/`: Lógica del juego en C# (gestión de turnos, movimiento del pingüino, interacciones táctiles y eventos de victoria).
* `/Assets/Scenes/`: Escenas del menú principal, selección de avatares y escenario de juego.
* `/Assets/Sprites/`: Arte gráfico de los avatares (Gato, Conejo, Ardilla, Koala), el pingüino y los objetos.

## 🚀 Instrucciones para Ejecutar el Proyecto
1. Clonar el repositorio: `git clone https://github.com/AlejandroVelasquezCuri/Atrapa-al-Pinguino-Unity.git`
2. Abrir **Unity Hub** y seleccionar la opción **Add / Agregar**.
3. Seleccionar la carpeta clonada del proyecto.
4. Abrir con la versión correspondiente de Unity LTS.
5. Ejecutar desde la escena `Assets/Scenes/MainMenu.unity`.
